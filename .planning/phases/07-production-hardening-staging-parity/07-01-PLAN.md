<threat_model>
### ASVS L1 Security Threat Model: Production Topology & Health Probes

| Threat ID | STRIDE Category | Threat Description | Mitigation Strategy |
|-----------|-----------------|--------------------|---------------------|
| T-07-01 | Denial of Service | Cascading container restarts if DB latency causes process liveness probes to fail | Decouple `/v1/health/live` (process responsiveness only) from `/v1/health/ready` (dependency checks) |
| T-07-02 | Denial of Service | Memory exhaustion in unbuffered reverse proxy from large payloads | Enforce `client_max_body_size 2M` in Nginx and bounded 16KB event sizes in SOC engine |
| T-07-03 | Information Disclosure | Server version and internal architecture leakage via HTTP headers | Nginx sets `server_tokens off;` and enforces HSTS, CSP, X-Content-Type-Options, X-Frame-Options |
| T-07-04 | Elevation of Privilege | Docker container escaping or resource monopolization on host | `docker-compose.prod.yml` enforces explicit CPU limits (2.0) and memory caps (2048M) |
</threat_model>
