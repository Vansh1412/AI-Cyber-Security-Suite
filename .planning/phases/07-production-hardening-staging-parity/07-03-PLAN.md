<threat_model>
### ASVS L1 Security Threat Model: Cross-Tenant Isolation & Reversible Containment

| Threat ID | STRIDE Category | Threat Description | Mitigation Strategy |
|-----------|-----------------|--------------------|---------------------|
| T-07-10 | Information Disclosure | Tenant B accessing Tenant A's alerts or incidents via predictable IDs or URL enumeration | Strict tenant filtering on all queries (`user_id == current_user.id`), returning HTTP 404/403 with no existence leakage |
| T-07-11 | Elevation of Privilege | Tenant B reading or hijacking Tenant A's real-time SSE stream events | Ephemeral 30s single-use stream tickets bound specifically to the authenticated tenant's identity |
| T-07-12 | Repudiation | Containment actions executed or reverted without persistent audit trail | Mandatory audit logging in `containment_action.audit_log` with user ID, timestamp, and previous state |
| T-07-13 | Denial of Service | Indefinite test runner hang during live SSE stream consumption | Wrap SSE client consumption in `asyncio.timeout(5.0)` with bounded event breaks |
</threat_model>
