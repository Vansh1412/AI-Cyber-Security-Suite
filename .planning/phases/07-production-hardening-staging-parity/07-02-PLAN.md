<threat_model>
### ASVS L1 Security Threat Model: Concurrency Race Conditions & Cache Failover

| Threat ID | STRIDE Category | Threat Description | Mitigation Strategy |
|-----------|-----------------|--------------------|---------------------|
| T-07-06 | Tampering | Race condition causing concurrent workers to double-claim the same outbox event or corrupt incident severity | Enforce PostgreSQL `FOR UPDATE SKIP LOCKED` and row-level locks (`with_for_update()`) on incident status and severity updates |
| T-07-07 | Denial of Service | Connection pool starvation crashing application during burst of 100 concurrent alert attachments | Configure connection pool with sufficient headroom (`pool_size=20, max_overflow=30`) and enforce async worker semaphores |
| T-07-08 | Denial of Service | Split-brain scheduler workers executing duplicate monitoring probes | Monotonic epoch fencing and session-level advisory locks (`pg_try_advisory_lock`) |
| T-07-09 | Denial of Service | Uncaught Redis connection exception cascading to client HTTP 500 error | Centralized Redis try/except fallback blocks in `cache_service` and `event_broadcaster` |
</threat_model>
