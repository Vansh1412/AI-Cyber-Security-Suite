<threat_model>
### ASVS L1 Security Threat Model: Concurrency Race Conditions & Cache Failover

| Threat ID | STRIDE Category | Threat Description | Mitigation Strategy |
|-----------|-----------------|--------------------|---------------------|
| T-07-05 | Tampering | Race condition causing concurrent workers to double-claim the same outbox event or corrupt incident severity | Enforce PostgreSQL `FOR UPDATE SKIP LOCKED` and row-level locks on incident status updates |
| T-07-06 | Denial of Service | Split-brain scheduler workers executing duplicate monitoring probes | Monotonic epoch fencing and session-level advisory locks (`pg_try_advisory_lock`) |
| T-07-07 | Denial of Service | Uncaught Redis connection exception cascading to client HTTP 500 error | Centralized Redis try/except fallback blocks in `cache_service` and `event_broadcaster` |
</threat_model>
